Slotted classes now transform `functools.cached_property` decorated methods (on the class itself and inherited from base classes) into slots, so they work without a `__dict__` -- including on frozen classes.
The cached value is computed once on first access and stored in the slot; the return annotation is preserved in the class's `__annotations__`.
A `cached_property` whose name collides with an attrs field or an explicit slot raises a `ValueError` instead of being silently overridden.
